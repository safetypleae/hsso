LEDGER INFORMATION

현재 저장된 관리정보를 그대로 출력

관리대장은 제품과 부서별 사용현황, 최신 MSDS 및 법정관리 판정에서 실제 저장된 값만 사용합니다.

  • 제품명, 제조사, 공급사와 제품 용도
  • 사용장소, 보관장소, 보유량과 평균 사용량·사용주기
  • 최신 MSDS 개정일과 제출번호
  • 관리대상·특별관리 및 대상 유해인자 포함 여부
  • 추가 검토가 필요한 제품 표시

WORKBOOK STRUCTURE

부서 목록과 부서별 제품 사용현황

첫 시트에는 MSDS 사용현황이 있는 부서와 제품 수, 등록·미등록·확인 필요 수가 정리됩니다. 부서명 링크를 누르면 해당 부서 관리대장 시트로 이동합니다.

부서별 시트는 제품-부서 사용현황 1건을 한 행으로 출력합니다. 구성성분 수만큼 행을 늘리지 않아 제품의 실제 사용현황을 한눈에 확인할 수 있습니다.

REGULATORY RESULTS

법정관리 판정과 해당 성분 표시

최신 MSDS 구성성분별 기존 판정 결과를 사용하며, 해당하거나 확인이 필요한 경우 실제 판정을 발생시킨 성분명을 같은 셀에 함께 표시합니다. 관련 성분이 없으면 비해당 또는 해당 성분 없음으로 출력합니다.

작업환경측정과 특수건강진단 항목은 실제 실시 대상 확정이 아니라 대상 유해인자 포함 여부로 표시됩니다.

FILTERS

검색·상태·부서 조건을 Excel에도 적용

MSDS 관리 화면에서 선택한 제품명·제조사 검색, MSDS·사용 상태와 부서 조건을 다운로드 파일에도 적용합니다. 부서가 선택되면 해당 부서만 포함되고, 화면의 페이지 단위 표시 제한과 관계없이 조건에 맞는 전체 사용현황을 출력합니다.

DOWNLOAD

Excel 관리대장 다운로드

MSDS 관리 화면에서 필요한 조건을 선택한 뒤 ‘Excel 다운로드’를 실행합니다. 생성 파일에는 출력 날짜가 포함되며 부서 목록과 각 부서 시트 사이를 내부 링크로 이동할 수 있습니다.

HOW TO USE HSSO

HSSO 사용방법

관리대장은 새로 내용을 입력하는 화면이 아니라, MSDS 관리에 저장된 제품·사용현황과 현재 검색 조건을 Excel로 정리하는 기능입니다.

  1. 관리정보 준비

    먼저 제품, 최신 MSDS와 구성성분, 부서별 사용현황을 등록·검토합니다. Excel에는 이때 저장된 최신 MSDS 정보와 법정관리 판정이 사용됩니다.

  2. 출력 범위 선택

    화학제품 목록에서 필요하면 ‘제품명·제조사 검색’, ‘MSDS·사용 상태’, ‘부서’ 조건을 선택하고 ‘검색’을 실행합니다. 조건을 두지 않으면 조회 가능한 전체 현황이 대상입니다.

  3. Excel 다운로드 및 확인

    ‘Excel 다운로드’를 누른 뒤 생성된 파일을 엽니다. 부서 목록 시트와 부서별 관리대장 시트에서 제품-부서 사용현황 1건당 1행, 최신 MSDS 정보, 법정관리 판정과 해당 판정을 발생시킨 성분을 확인합니다.

확인 안내관리대장은 HSSO에 현재 저장된 정보를 기준으로 생성됩니다. 미등록 또는 확인 필요로 표시된 정보와 법정관리 판정은 원본 MSDS 및 사업장의 실제 작업조건과 함께 최종 확인해야 합니다.
