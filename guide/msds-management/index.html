PRODUCT INFORMATION

제품 기본정보를 공통 기준으로 정리

회사에서 사용하는 화학제품별로 제품명, 제조사, 공급사, 제품코드와 일반적인 용도를 등록합니다. 같은 제품을 여러 부서에서 사용할 때 제품정보는 공유하고 부서별 사용정보는 구분합니다.

MSDS VERSIONS

MSDS 원문과 최신 버전 관리

PDF 원문과 작성일, 개정일, 제출번호를 버전별로 보관합니다. 새 버전을 등록해도 이전 원문을 유지하면서 현재 적용할 최신 MSDS를 구분할 수 있습니다.

  • 등록된 PDF 원문 열람과 다운로드
  • 작성일·개정일·제출번호 관리
  • 현재 버전과 이전 버전 이력 확인

COMPOSITION

구성성분과 CAS 번호 확인

MSDS 분석 결과에서 구성성분명, CAS 번호와 함유량 표현을 확인하고 필요한 경우 사용자가 수정한 뒤 저장합니다. 자동으로 확정하기 어려운 값은 확인이 필요한 상태로 구분합니다.

DEPARTMENT USAGE

부서별 사용·보관 현황 관리

제품을 사용하는 부서마다 사용 용도, 사용장소, 보관장소, 현재 보유량과 평균 사용량·사용주기를 기록합니다. 회사 공용 제품정보를 중복 등록하지 않고 실제 사용현황을 부서 단위로 나눌 수 있습니다.

REGULATORY REVIEW

법정관리 대상 유해인자 포함 여부 확인

최신 MSDS의 저장된 구성성분별 기존 판정 결과를 이용해 관리대상 유해물질과 특별관리물질 해당 여부를 확인합니다. 작업환경측정 및 특수건강진단은 각 대상 유해인자가 제품 구성성분에 포함됐는지를 표시합니다.

  • 관리대상 유해물질 및 특별관리물질 판정
  • 작업환경측정 대상 유해인자 포함 여부
  • 특수건강진단 대상 유해인자 포함 여부
  • 정확한 자동 판정이 어려운 항목의 확인 필요 표시
확인 안내작업환경측정·특수건강진단 항목은 대상 유해인자의 구성성분 포함 여부를 나타냅니다. 실제 실시 의무나 최종 적용 여부를 자동으로 확정하지 않으며, 작업조건과 관련 기준을 함께 검토해야 합니다.
