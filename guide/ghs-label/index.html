MSDS PDF에서 경고표지 작성에 필요한 정보를 확인하고, 분석 결과를 직접 검토·수정한 뒤 원하는 크기의 경고표지를 PDF로 출력할 수 있습니다.

PREPARE

원본 MSDS PDF 준비

제품에 해당하는 MSDS PDF를 준비해 업로드합니다. 문서의 문자와 표 구성이 제품마다 다를 수 있으므로 분석 후에는 반드시 원본 내용과 비교해야 합니다.

ANALYSIS

경고표지 항목 자동 분석

업로드한 PDF에서 경고표지에 사용할 정보를 찾아 입력을 돕습니다.

  • 제품명과 공급자 정보
  • GHS 그림문자와 신호어
  • 유해·위험문구(H 문구)
  • 예방·대응·저장·폐기 예방조치문구(P 문구)

REVIEW AND EDIT

분석 결과 확인과 수정

자동으로 입력된 제품명, 그림문자, 신호어와 문구를 원본 MSDS와 대조합니다. 누락되거나 다르게 읽힌 내용은 사용자가 직접 수정할 수 있으며, 수정 결과가 경고표지 미리보기에 반영됩니다.

PREVIEW AND PDF

경고표지 미리보기와 PDF 출력

사용 환경에 맞는 표지 크기를 선택하고 A4 출력 기준 미리보기를 확인합니다. 최종 확인이 끝나면 경고표지를 PDF로 다운로드할 수 있으며, 로그인한 사용자는 작성한 문서를 내 문서에 저장할 수 있습니다.

최종 확인자동 분석 결과만으로 경고표지 내용을 확정하지 마세요. PDF 출력 전 제품의 원본 MSDS와 관련 기준을 사용자가 직접 확인하고, 확인되지 않은 항목은 임의로 채우지 않아야 합니다.
