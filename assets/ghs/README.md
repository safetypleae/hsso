# GHS pictogram assets

The SVG files in this directory are public-domain GHS pictogram vector drawings
from Wikimedia Commons, derived from the UNECE GHS pictogram source files.

- Official reference: https://unece.org/labels-ghs
- Vector collection: https://commons.wikimedia.org/wiki/Category:GHS_pictograms_(Vector_drawings)

File names `ghs01.svg` through `ghs09.svg` correspond to the UNECE GHS codes.
